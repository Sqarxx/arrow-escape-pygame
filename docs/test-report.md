# 测试记录

测试环境：Windows、Python 3.13.9、Pygame 2.6.1

## 运行方式

```powershell
python -m unittest discover -v
```

## 作业要求测试

| 编号 | 测试内容 | 预期结果 | 实际结果 | 结果 |
| --- | --- | --- | --- | --- |
| T01 | 点击前方无阻挡的箭头 | 箭头飞出并消失 | 返回 `EXITED`，箭头数减少 | 通过 |
| T02 | 点击前方有阻挡的箭头 | 不消失，失误减 1 | 返回 `BLOCKED`，箭头保留并显示碰撞反馈 | 通过 |
| T03 | 点击边缘且朝外的箭头 | 正常消失，不越界 | 四个边缘方向均无异常 | 通过 |
| T04 | 清空本关箭头 | 显示通关并可进入下一关 | 状态进入 `level_clear` | 通过 |
| T05 | 失误次数耗尽 | 显示失败并允许重开 | 状态进入 `failed` | 通过 |
| T06 | 游戏中重新开始 | 布局和失误次数恢复 | 状态与关卡初始值一致 | 通过 |
